# React JSX 실습
## 시작하기

**프로젝트 생성**
```bash
npm create vite@latest
```

- Project Name: 프로젝트명
- Framework: React
- Variant: JavaScript
- Linter: ESLint

**프로젝트 실행**
```bash
npm install   # 최초 1회
npm run dev   # 프로젝트 실행
```

**문법 오류 확인(테스트)**
```bash
npm run line
```

**프로젝트 실행 종료**
`Ctrl` + `C` => 일괄 작업을 끝내시겠습니까? `Y` 입력
